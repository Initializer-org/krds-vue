# 스낵바 Snackbar

스낵바는 사용자 행동에 대한 결과나 서비스 이용 중 발생한 중요도 낮은 메시지를 추가 행동과 함께 제공하는데 사용한다. 사용자의 주요 흐름을 방해하지 않으면서, 되돌리기 또는 다시 시도 등과 같이 간단한 조치를 포함한다.

## 기본

`<KrdsSnackbar />`를 App.vue에 한 번만 두고, 어느 컴포넌트에서든 `useSnackbar().show({ title, message, icon, action, onAction })`로 띄웁니다. `action`에 버튼 이름을 주면 텍스트 작업 버튼이 생기고 누르면 `onAction`을 부른 뒤 닫힙니다. 닫기 버튼이나 `hide()`로 닫으며, 기본으로는 자동으로 사라지지 않고 `duration`(ms)을 주면 그 시간 뒤 닫힙니다. `icon`은 메시지 뜻을 강조할 때만 씁니다(`ico-success-fill`, `ico-information-fill`, `ico-error-fill`). 화면낭독기가 읽도록 `role="status"` 영역은 항상 두고 표시할 때만 내용을 넣습니다. 화면 하단에 고정되므로 예제를 별도 화면(iframe)에 띄웁니다.

## 사용 지침

- 되돌리기, 다시 시도, 목록 이동처럼 사용자가 즉시 할 수 있는 간단한 조치를 메시지와 함께 줄 때 씁니다. 작업 버튼은 1개만 둡니다.
- 중요하거나 긴급한 메시지, 두 문장 이상의 설명은 긴급 공지나 모달을 씁니다. 추가 행동이 없는 한 줄 알림은 [토스트](/components/toast)를 씁니다.
- 한 페이지에 스낵바를 하나만 표시하고, 여러 개를 겹치거나 쌓지 않습니다. 떠 있는 동안 다시 `show()`하면 내용이 바뀝니다.
- 하단 탭바나 플로팅 버튼과 겹치지 않게 `--krds-snackbar--bottom` 변수로 위치를 조정합니다.
- 원본 KRDS에 구현이 없는 컴포넌트로, 가이드의 구조·위치와 디자인 토큰으로 만들었습니다.

## API

## KrdsSnackbar

전역 스낵바를 그리는 자리입니다. App에 한 번만 두며 props·events가 없습니다.

## useSnackbar()

| 이름            | 설명                                                                                                                                                                                   |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `show(options)` | 스낵바 표시. `title`(필수), `message`, `icon`(아이콘 클래스), `action`(작업 버튼 이름), `onAction`(작업 버튼을 눌렀을 때, 호출 뒤 닫힘), `duration`(ms, 기본 0으로 닫기 버튼까지 유지) |
| `hide()`        | 스낵바 닫기                                                                                                                                                                            |
